# Ghost Clone

Мод записывает ваше прохождение уровня (классический режим и платформер) и при
следующем заходе на этот же уровень показывает полупрозрачного **клона-призрака**,
который повторяет движения из прошлой попытки. Призрак использует те же иконки,
цвета и скин, что и вы — он выглядит как настоящая копия игрока, только прозрачная.

## Возможности

- Автоматическая запись каждой попытки (можно отключить в настройках)
- Воспроизведение лучшей по проценту попытки в виде клона
- Настраиваемый цвет и прозрачность призрака
- Поддержка всех игровых режимов: куб, корабль, шар, НЛО, волна, робот, паук, свинг
- Отдельное сохранение для каждого уровня (`ghost_<levelID>.json`)
- Удобное меню управления призраком прямо в паузе
- Запись не ведётся в Practice Mode — призрак всегда честный

## Как это работает

1. Заходите на уровень в обычном режиме (не Practice Mode).
2. Мод записывает координаты, поворот, отражение и игровой режим каждый кадр.
3. Если попытка закончилась лучшим результатом (по %), чем предыдущая запись —
   она сохраняется на диск.
4. При следующем заходе на уровень рядом с вами появляется призрак из лучшей
   сохранённой попытки, плавно интерполирующий движение между кадрами.

## Меню призрака (кнопка в паузе)

Нажмите на иконку призрака в меню паузы, чтобы открыть панель управления:

- включить/выключить показ призрака;
- изменить цвет и прозрачность;
- посмотреть список всех сохранённых записей и удалить ненужные.

## Настройки мода

| Настройка | Описание |
|---|---|
| Прозрачность призрака | 0 — призрак невидим, 1 — непрозрачен |
| Автозапись попыток | Включает/выключает автоматическую запись |
| Цвет призрака | RGB-цвет подсветки силуэта |
| Кнопка в меню паузы | Показывать ли кнопку открытия меню призрака |
